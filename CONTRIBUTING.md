# Contributing to Awesome Harness Engineering

Thank you for your interest in contributing!

## Guidelines

- The repository must be related to harness engineering (agent harnesses, CI/CD harnesses, test harnesses, evaluation harnesses, or harness-first development practices)
- It must have at least 1,000 stars (or be highly relevant with 100+ stars and actively maintained)
- It must be actively maintained (updated within the last 2 years)
- Add it to the most relevant category
- Keep descriptions concise and in English

## How to Contribute

1. Fork this repository
2. Add the repository to the correct category in `README.md`
3. Follow the existing format: `| [**owner/repo**](url) | ⭐ stars | \`Language\` | description |`
4. Submit a Pull Request with a brief description

## Quality Standards

- No duplicates
- No archived repositories
- Descriptions should be informative, not promotional
- Prefer repositories with clear documentation and active communities

## Categories

- **Agent Harness Frameworks** — core agent frameworks using harness engineering principles
- **CI/CD & DevOps Platforms** — industrial CI/CD with harness branding or harness-first architecture
- **LLM Evaluation Harnesses** — LLM and agent evaluation frameworks
- **Harness Engineering Guides** — tutorials, playbooks, and educational content
- **Skills, Memory & Context Toolkits** — memory, skills, and context management tools
- **Benchmarking & Testing Harnesses** — test frameworks and benchmark tools
- **Security & Fuzzing Harnesses** — security research and fuzzing tools
- **Awesome & Curated Lists** — curated lists of harness engineering resources
- **Miscellaneous Harness Projects** — other notable harness-related projects
